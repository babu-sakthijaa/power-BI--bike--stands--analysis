🚲 Bike Sharing Data Analysis Dashboard | Power BI

📌 Project Overview

This project is an interactive Bike Sharing Analysis Dashboard developed using Microsoft Power BI. The dashboard helps analyze bike-sharing operations through key performance indicators (KPIs), visualizations, and interactive filters.

The main objective is to explore bike availability, bike stand availability, distance-related metrics, and city-level distribution to gain useful business insights.

🎯 Project Objectives

- Analyze total available bikes and bike stands.
- Understand bike availability across different contracts.
- Explore city-wise distribution.
- Analyze operational metrics using interactive visualizations.
- Present key information through an interactive Power BI dashboard.

🛠️ Tools & Technologies

- Microsoft Power BI – Dashboard development and visualization
- Power Query – Data preparation and transformation
- DAX – KPI calculations and measures
- Data Modeling – Organizing data for analysis

📊 Dashboard Features

The report contains five pages with different visualizations and analysis components.

- KPI Cards:
  - Total Bikes
  - Total Bike Stands
  - Total KM
- Contract-wise bike availability analysis.
- Contract-wise available bike stand analysis.
- City-wise distribution using pie charts.
- Interactive slicers for Contract Name, Banking, and City.
- Multiple chart types for exploring operational data.

📈 Key DAX Measures

The report includes the following KPI measures:

- "TOTAL-BIKES"
- "TOTAL-STANDS"
- "TOTAL-KM"

5. Use the slicers to interact with the report.
